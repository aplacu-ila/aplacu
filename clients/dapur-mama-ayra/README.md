# Dapur Mama Ayra

**Project type:** Product campaign / food & beverage

**Design direction:** Flexible. Owner preference determines the final direction.

## Example production brief

Create a promotional asset for a pempek package using the owner's actual product photography. The primary communication should make the package name, price, included items, product photo, and ordering path immediately understandable.

## Production lesson

A beautiful design is not automatically the right design. The owner's taste, product photography, audience, and sales objective determine the appropriate visual language.

## Asset lifecycle

```text
Brief → Concept → Proof → Owner Review → Revision → Approved → Production
```

Client-specific source files and unpublished assets remain private.
